操作步骤

四步走完，就能看到出生点。

下面每一步都可以单独排查：卡在哪一步，就直接在群里报这一步的现象。

安装 Java 21

去 Java 官网或群文件下载 Java 21（64 位）并安装。安装完成后，老版本 Java 不必卸载，启动器里选择 Java 21 的路径即可。

# 检查是否装好（Windows 打开 PowerShell 输入）
java -version
# 正常输出示例：openjdk version "21.0.x"

下载并导入 LJC 整合包

在 QQ 群文件里下载最新版整合包，然后在启动器中选择「导入整合包 / 从压缩包安装」，选中刚下载的 zip 文件，等待启动器解压完成。

跳到整合包下载说明

整合包

整合包只在群文件发布。

这样做是为了保证所有玩家的模组版本完全一致——版本错一个数字，进服就会被踢。 群文件里会持续更新最新版，更新后群公告会同步说明。

  • 核心为 机械动力（Create 6 系列），含列车、航空学等常用扩展。
  • 附带配方查询、地图与小地图等基础辅助模组，开箱即用。
  • 每次大版本更新都会保留存档兼容，不需要重开世界。

账号与皮肤

不用正版，也能有自己的皮肤。

服务器采用离线登录，并自建了皮肤站。注册一次，之后每次进服都会自动显示你的皮肤与披风（如有）。

注册皮肤站

皮肤站地址与注册流程见 QQ 群公告。注册时使用的游戏 ID，必须和你启动器里的离线 ID 完全一致。

STEP 01

登录方式

在多人游戏界面选择「离线登录」，或按群公告把皮肤站地址配置为验证服务器，保持 ID 一致即可。

STEP 02

皮肤不显示？

先确认 ID 大小写完全一致，再重启一次客户端。仍不显示就把 ID 和截图发到群里，管理可以帮忙查。

STEP 03
安全提醒

皮肤站密码请勿与其它网站重复。管理组不会以任何理由向你索要密码、邮箱验证码或正版账号信息； 任何私聊要账号的，都是骗子，请立刻截图发到群里。

进不去？先对照这张表。

常见进服报错与处理方法
现象 / 报错 常见原因 处理方法
启动器报 Java 版本错误 使用了 Java 8 / 17 安装 Java 21，并在启动器设置里手动指定 Java 21 的可执行文件路径。
登录时提示 Invalid session 选了正版登录，但账号未登录或非正版 改成「离线登录 / 第三方登录」，并确认 ID 与皮肤站一致。
连接超时 / 无法连接 地址填错、网络波动、服务器重启中 核对地址为 mc.ljcyun.xyz:20058（冒号是英文半角），稍等几分钟再试，或到群里问一句。
进服秒退，提示模组不匹配 自己装了额外模组或用了旧版整合包 删掉自装模组，重新从群文件下载最新整合包导入。
加载世界时卡住 / 内存溢出 分配内存过低 把启动器分配内存调到 6–8 GB，并关闭占内存的后台程序。
能进服但很卡、方块回弹 本地网络延迟高 关闭后台下载与加速器（部分加速器会干扰），换个时段再试；持续异常请反馈到群里。
皮肤 / 披风不显示 ID 大小写不一致、未绑定皮肤站 确认 ID 完全一致并重启客户端，仍未解决把 ID 发到群里。
