01 · 进服相关

第一次进服，先看这几条。

从账号到客户端版本，进服前后最容易卡住的地方都在这里。

需要正版账号才能进服吗？

不需要。服务器支持离线登录，没有正版账号也能直接进服，皮肤通过服务器自建的皮肤站加载。

第一次进服前，建议先加 QQ 群 1064599211 看一遍群公告：整合包、皮肤站说明和维护通知都发在里面。

怎么进服？大概分几步？

三步，熟悉启动器的话五分钟就能进游戏：

  • 安装 Java 21，群文件里有安装包，装完不用额外配置。
  • 在启动器里导入 LJC 整合包，等待依赖下载完成。
  • 启动游戏 → 多人游戏 → 添加服务器 → 地址填 mc.ljcyun.xyz:20058 → 加入服务器。

带截图的完整步骤见 进服指南。

客户端要用什么版本？整合包在哪里下载？

客户端是 Java 版 1.20.1 + Forge，核心是机械动力（Create 6 系列）整合包。

整合包与完整模组清单都放在 QQ 群文件里，下载后直接在启动器导入即可。请使用群里发布的版本：自己拼的模组列表很容易因为不一致被服务端拒绝连接。下载说明整理在 进服指南的整合包部分。

手机上的基岩版能进服吗？

不能。LJC 是 Java 版服务器（1.20.1 + Forge），基岩版客户端无法直接加入，手机端目前也没有受支持的进服方式。

整合包对性能要求较高，建议在电脑上游玩，体验也更接近服务器的设计预期。

连接时提示版本不匹配，或者干脆进不去怎么办？

先核对三件事：客户端是不是 1.20.1 + Forge、有没有用群文件里的整合包、模组列表有没有自己增减。

三项都一致还是进不去，把启动器的完整报错截图发到 QQ 群，管理组会帮你看。常见报错的处理方式也写在 报错排查 里。

02 · 账号与皮肤

离线登录，也能有自己的样子。

服务器不需要正版，身份和皮肤由 ID 与自建皮肤站承担。

皮肤站怎么用？皮肤怎么上传？

皮肤站是服务器自建的登录与皮肤服务。流程很简单：按群公告的说明注册账号，上传一张符合 Minecraft 规格的皮肤图片，然后在启动器里用同一个 ID 登录，进游戏就能看到自己的皮肤。

皮肤没生效时，先确认启动器里的 ID 与皮肤站账号完全一致，再重启一次客户端。

皮肤站的地址是什么？

皮肤站地址在 QQ 群公告内提供，这里不单独列出。进群后看公告里的皮肤站一条，按里面的地址注册与上传皮肤。

地址如果发生变动，也会先在群公告同步，照公告为准就不会走错。

离线登录有什么限制吗？

玩法上没有区别，不会因为离线登录被限制功能。需要注意的是身份由游戏 ID 决定，所以请固定使用自己的 ID，不要占用别人的名字。

皮肤需要皮肤站加载才会显示；没上传皮肤时就是默认外观。

想用的 ID 已经被别人占用了怎么办？

在 QQ 群里说明情况，管理组会核对该 ID 的历史登录记录。如果确认是你长期使用的名字，会协助你处理。

不建议为了抢名字反复更换 ID：领地、容器权限和建筑归属都绑在 ID 上，换名字容易把自己的东西弄丢。

换了电脑之后，皮肤和进度还在吗？

都在。皮肤跟着皮肤站账号走，重新登录就会自动加载；建筑、机器、背包与领地数据都存在服务端，不会因为换客户端而丢失。

唯一的例外是单人存档：它保存在本地，服务器不代管，需要你自己备份。

03 · 玩法与技术

关于圈地、建机器和模组。

这一组问题问得最多，尤其是领地保护和大型机器报备。

领地怎么圈？怎么给别人权限？

服务器提供领地保护。先用圈地指令把地块圈起来，再用权限指令把信任的玩家加进领地，重要箱子可以额外上锁。

具体的指令组与权限说明写在群公告里，也可以在游戏内输入 /help 查看当前可用指令。建议动工前先圈地，别等建完再补。

服务器会删档吗？我造的机器能留多久？

不会删档。地图与玩家数据长期保留，版本更新采用兼容迁移的方式，不整档重置。

也就是说，你现在开始建的基地和产线，可以一直放在原地。

服务器卡顿、掉线怎么办？

先区分是个人的问题还是全服的问题。只有你卡，多半是内存分配、视距或光影设置偏高，调低之后会明显改善。

如果群里大家都卡，通常是某台机器在堆积实体或加载区块。把坐标和现象发到 QQ 群，管理组会去查；维护与重启也会提前在群公告通知。

可以带自己的模组进服吗？

不可以随意加装。客户端模组列表需要与服务器一致，单方面加模组通常会被拒绝连接。

确实需要的功能性模组，先在群里问一下管理组，确认不会影响服务端和其他玩家再装。

大型机器能建吗？TNT 世吞、刷怪塔要不要报备？

能建，但需要先报备。把坐标和用途发到 QQ 群，管理组确认不会与别人的建筑、领地冲突之后再动工。

计划建在公共设施或别人基地附近的，请先和当事人协商。这条同样写在 服务器规则 里。

服务器现在是什么玩法？新人能跟上吗？

主玩法是机械动力（Create 6 系列）整合包，同时保留了完整的生电环境，红石玩家也有足够的空间。

没接触过机械动力的新人可以先跟着群里的教程从水车、蒸汽机做起，再做传送带和列车；卡住了在群里问，基本都有人答。

04 · 管理与申诉

出问题找谁，怎么找。

举报、申诉和权限申请都通过 QQ 群提交，处理依据是服务端行为日志。

被封禁或者被限制权限了，怎么申诉？

在 QQ 群提交游戏 ID、发生时间、坐标与截图，管理组会调取行为日志核对当时的方块与容器改动，然后回复处理结果。

确认是误判会解除处理，并恢复受影响的部分。完整流程见 规则页的申诉部分。

发现有人破坏、偷东西或者作弊，怎么举报？

把坐标、大致时间和截图或录像发给管理组。方块与容器的改动都有行为日志可查，确认之后可以回滚被破坏的部分。

举报不需要先和对方争吵，也不用担心被针对；举报人的信息不会被公开。

可以申请管理员吗？

管理组不公开招募，通常从长期在线、熟悉规则、愿意帮新人的玩家中邀请。

想参与服务器事务，可以先做活动志愿者、帮忙整理教程或者带新人，做得多自然会被看到。

能申请建筑权限或者创造模式吗？

服务器以生存玩法为主，不向个人发放创造模式权限，所有建筑都在生存条件下完成，这样作品才有可比性。

活动与比赛期间会开放专门的比赛场地或创造区域，具体报名与使用方式看群公告。

管理组会查看我的箱子或者私聊内容吗？

不会无故查看。行为日志只在处理举报、申诉和回滚破坏时被调取，用来确认方块与容器的改动记录。

正常的建造、交易和玩家之间的交换不会被干预。
